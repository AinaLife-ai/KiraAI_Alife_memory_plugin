# Alife Memory for KiraAI

长期记忆插件，让机器人记得住、找得准、能自己反思纠错。

> 灵感源于 [Alife](https://github.com/BDFFZI/Alife) 4.2.3 的分层记忆设计。
> 感谢作者半点星光（BDFFZI）的精彩设计，让本项目有了坚实的起点。

---

## 小白也能懂：这是干什么的？

装了它之后，你的机器人就有了「长期记忆」——它会主动记下聊天中重要的信息，下次聊到相关话题时自然想起，不用你每次都重复。

就像给机器人装了一个大脑里的日记本。它会：

- **自己抄笔记** — 聊完天自动把重要信息存下来
- **你主动告诉它** — 你也能随时让它记住某事
- **需要时想起来** — 聊到相关话题时自动翻出旧记忆参考
- **自己改错** — 发现记错了会自己更正（背后自动审校）
- **不会膨胀炸掉** — 旧版本自动清理，不占空间

---

## 核心特点

| 特点 | 说明 |
|---|---|
| **主动与自动精准跨维度检索** | LLM 主动记、系统自动记，跨会话跨用户关联 |
| **异步分层压缩** | 不阻塞对话，轮数/Token/消息数三重触发 |
| **跨来源去重合并** | 同一事实不同来源自动合并，不重复 |
| **后台反思纠错** | 自动对比新证据旧记忆，高置信度才修改 |
| **修正审计链** | 改过的旧版本保留，随时可回溯 |
| **全按钮 WebUI** | 记忆浏览、修正、删除、检索、配置都在侧边栏完成 |
| **互斥兼容** | 自动检测并禁用冲突的记忆插件，数据可迁移 |
| **三重注入预算** | Token+字符数+行数三保险，不撑爆上下文 |
| **绝对日期转换** | "3天后"→"2026-09-09"，记忆永不过期 |

## 快速安装

### 方法一：GitHub 一键安装（推荐）

1. 打开 KiraAI WebUI → 插件管理
2. 点 "Install from GitHub"，输入仓库 URL：
   ```
   https://github.com/znq19/KiraAI_Alife_memory_plugin
   ```
3. 安装完成后重启 KiraAI
4. 到侧边栏点击「长期记忆」即可管理你的记忆

### 方法二：手动安装

1. 下载 `alife_memory_kiraai_v1.0.0.zip`
2. 解压到 KiraAI 的 `data/plugins/alife_memory/` 目录
3. 在 WebUI 插件管理中启用
4. 重启 KiraAI

### 安装后自动行为

- 如果检测到 `kira_plugin_simple_memory`（KiraAI 内置简单记忆）或 `kira_plugin_kiraos`（KiraOS 海马体记忆），**会自动禁用它们**，并把已有记忆迁移到本插件（原始数据不删除）
- 原记忆插件的数据文件保留不动，可随时手动恢复

## WebUI 侧边栏使用

安装后侧边栏会出现「长期记忆」入口，点进去有 5 个页面：

| 页面 | 能做什么 |
|---|---|
| **总览** | 看记忆总数、待压缩情况、触发状态，一键清理过期 |
| **记忆管理** | 浏览所有记忆、修正内容、删除不需要的 |
| **检索** | 搜索历史记忆，测试召回效果 |
| **任务** | 查看压缩/审校任务状态 |
| **配置** | 调参数（都在表单里，不用改代码） |

> 💡 **配置页改动后记得点"保存配置"**

配置页面顶部提示：**管理记忆内容推荐用「记忆管理」「检索」等页面，比改配置更方便直观。**

## LLM 可用工具（共 6 个）

安装后机器人在对话中会自动获得以下能力：

| 工具 | 作用 | 说人话 |
|---|---|---|
| `remember_fact` | 主动记录一件事 | 让机器人记下你告诉它的重要信息 |
| `search_long_term_memory` | 搜索旧记忆 | 让它回想过去的事 |
| `get_memory_detail` | 看单条记忆详情 | 查看某条记忆的完整内容和来源 |
| `list_all_memories` | 列出现有记忆 | 看看自己都记得什么 |
| `correct_long_term_memory` | 修正记忆 | 发现记错了就改 |
| `forget_long_term_memory` | 删除记忆 | 想让它忘掉某件事 |

记忆自动附带**类型标签**（关于我的 / 我喜欢的 / 正在发生的 / 去哪查 / 日常的），偏好和项目类还自动记录原因和适用场景。

## 配置项一览

### 记忆总控
| 参数 | 默认 | 说明 |
|---|---|---|
| 启用记忆系统 | true | 总开关 |
| 自动记录对话 | true | 聊天后自动记 |
| 自动注入 | true | 相关记忆自动注入上下文 |
| 被动召回 | true | 新用户或弱检索时自动补充 |
| 注入 Token 上限 | 1500 | 每条记忆注入的预算 |
| 注入条数上限 | 8 | 每次最多注入几条 |
| 注入行数上限 | 30 | 行数截断 |
| 消息保留天数 | 7 | 已压缩原始消息保留天数 |
| 旧版本保留天数 | 30 | 修正旧版本超过此天数后清理 |
| 自动归档天数 | 0=关闭 | >0 时启用，旧记忆自动归档 |
| 归档影响最低层级 | =最高层 | 低于此层级才归档，最高层保护 |

### 三重触发压缩
| 参数 | 默认 | 说明 |
|---|---|---|
| 触发模式 | rounds | rounds/tokens/messages/either |
| 轮数阈值 | 10 | 满多少轮触发压缩 |
| Token 阈值 | 10000 | 满多少 Token 触发 |
| 消息数阈值 | 50 | 满多少条消息触发 |

### 压缩与分层
| 参数 | 默认 | 说明 |
|---|---|---|
| 压缩模型 | — | 可选快速模型，留空默认 |
| 压缩触发概率 | 0.8 | 避免连续压缩影响互动感 |
| 每批消息数 | 10 | 每次压缩多少条 |
| 最大压缩层级 | 5 | 分层压缩的顶层 |

### 检索与注入
| 参数 | 默认 | 说明 |
|---|---|---|
| 默认检索范围 | linked | linked/session/global |
| 默认结果数 | 5 | 每次检索返回条数 |
| 时间衰减半衰期 | 45天 | 旧记忆逐渐降权 |

### 后台反思
| 参数 | 默认 | 说明 |
|---|---|---|
| 启用审校 | true | 自动检查冲突 |
| 审校间隔 | 1800秒 | 每半小时检查一次 |

## 数据存储

- 数据库：`data/plugins/alife_memory/memory.sqlite3`
- 原始对话消息和记忆表分离，互不影响
- 已压缩消息 7 天后自动清理（可配）
- 修正旧版本 30 天后自动清理（可配）
- 用户主动删除的记忆标记 `deleted=1`，保留审计不物理删除

---

## 互斥兼容

| 冲突插件 | 行为 |
|---|---|
| `kira_plugin_simple_memory`（KiraAI 内置简单记忆） | 自动禁用，迁移数据 |
| `kira_plugin_kiraos`（KiraOS / 海马体记忆） | 自动禁用，迁移数据 |

原插件数据库和文件**不删除**，可手动恢复。
