# 2.1.1：结构化输出与回忆去重

## 本轮需求与边界

修复压缩/审计频繁报 structured_output_rejected、ValueError；解释 legacy 人物/会话名称并避免错误身份绑定；让昵称与事实的审校依据在前端可见；减少读取工具里的多层转义和长串 ID；改善“还有别的吗”时重复提供同一批内容。旧记忆不得破坏，仍严格校验模型输出，动态上下文仍在 user 区域，向量默认关闭。新 PR 从已合并 PR15 的 main（f51876ecf8466d8c583eeb22c4a3f79f8de7ff9e）开始。

## 已复现的插件问题

- 压缩和审计共用的提示要求生成 summary，审计契约却只接受 actions；提示未说明审计 source_ids 指事实 ID，而压缩 source_ids 指原始记录 ID。
- 审计的引用、重叠操作、跨主体合并校验在数据库写入入口才执行，模型纠错重试捕捉不到这类 ValueError。
- 格式校验丢弃具体字段位置，仅要求“重新遵守 Schema”，无法定向修复。
- 名称不变时直接返回，人工填写的确认原因没有保存。
- ReadMemoryArchive 默认重复给出摘要、序列化的整批正文与全部子 ID。用户提供的文本样本中有70个子存档 ID；不是向量。样本的默认工具返回投影从18809字符降至2401字符，减少87.2%。这是单一样本的字符量比较，不是实际Token或延迟基准。样本正文及用户标识不纳入仓库。
- 读取自身旧记忆的工具返回也被捕获为新经历。真实核心 ToolResult 接口测试复现记录数1→2，修复后自身读取不增加记录，外部工具的新信息仍增加记录。

## 实现

1. 分开说明压缩和审计的输出及 ID 语义。共享同一审计校验函数，在模型重试边界和事务入口均验证；keep/correct不能混入其他事实，合并继续限制同会话、主体、类别及不重叠操作。
2. 错误反馈提供字段路径与类型、JSON行列或有限的已知错误码；屏蔽原文、额外字段名和异常响应正文。不去围栏、不猜字段、不放宽类型或关系校验。失败仍不提交该批次。审计按输入软预算选择完整事实及完整证据，最少一条；压缩保留最少两条的完整证据。极长单条可能超过软预算。
3. legacy 标识保留。global/unscoped显示为迁移归档区；仅显式携带适配器前缀的人物归档可参考对应账号称呼。裸数字不自动认定平台、合并身份或重写所属会话。历史事实中的 legacy 主体补入名称目录，名称是显示层信息。
4. 人物卡片直接展示最近依据，名称历史默认展开；同名的人工确认也新增记录。事实卡片和证据区展示最近五次修改/审计原因，完整历史仍保存在库中；keep审计也保存依据。
5. ReadMemoryArchive默认压缩存档不返回整批正文；children每页20个，可用child_offset/child_count继续。include_content=true返回完整正文、修改历史及迁移来源；原始叶子直接给原文。只解码程序自有的完整JSON归档/消息外壳，文本原样保留。搜索仅投影必要的来源、摘要和层级。
6. 显式“还有别的吗”等追问沿用近期主题，排除已返回存档；SearchMemoryArchive支持next_batch和exclude_ids。窗口仅驻内存，按会话、参与用户及访问范围隔离，30分钟过期、最多256组，每组最多200个记录ID/事实ID。重启或换主题可重新召回。已提供不等于Bot已说出口，仍需Bot结合聊天历史判断；不会承诺模型绝不重复。
7. 自身只读记忆工具的返回以当前事件内精确摘要识别，不再次写成经历；最多保留128个摘要，不缓存私密正文。聊天回复、外部工具感知仍照常捕获。已存在的重复旧记录不自动删除。

## 用户理解：记忆与回忆

- 被动记录：启用捕获后，聊天、已解析的图片/语音描述、Bot回复和外部工具结果写为L0；记忆读取本身不复制为新经历。
- 分层压缩：默认L0达到100条时，选最早70条整理成L1；上层达到4条时选最早3条再上一层，默认最高L8。原文保留，原节点移出活跃区并连接到父节点，仍可逐层读取。
- 触发：聊天回复后和后台每30秒检查达到阈值的会话，每次按默认0.4概率入队。并非每100条立即同步压缩。单个任务最多处理64轮，后续检查接着处理积压；失败自动冷却5分钟，手动可立即重试。
- 审计：默认每1800秒，最多20条事实，受完整证据输入预算约束；优先审计尚未审计或较早审计的事实。可保留、修正或在严格条件下合并。
- 被动回忆：每次聊天请求把当前活跃记忆、永久记忆、相关事实与跨会话检索结果组合进user区域，带来源和时间；系统区只有固定使用规则。
- 主动记忆：Bot可调用Memorize保存永久核心记忆，不参与自动压缩；Forget只是移出常驻，原文仍在。
- 主动回忆：Bot自行调用搜索、读取子存档和画像工具。启用主动感知并配置目标会话后，默认每小时发内部提醒，由Bot判断是否有合适事项跟进，不保证每次都会发言。
