# 2.2.7：开屏动画背景首帧即不透明

## 问题

2.2.6 把 `#boot` 改成静态标记后，用户仍反馈"先看到主页、再弹出动画"。原因是遮罩本身带了一条淡入动画：

```css
.boot { animation: boot-in 0.5s both, boot-out 0.6s 3s forwards; }
@keyframes boot-in { from { opacity: 0 } to { opacity: 1 } }
```

`boot-in` 从 `opacity: 0` 开始，所以**前 0.5 秒遮罩是透明的**，页面从底下透出来——视觉上就是"页面先出来，然后动画才浮现"。

## 改动

- `.boot` 去掉 `boot-in`，只保留 `boot-out` → **背景从第一帧就是不透明的**，首屏绘制即完全盖住页面；
- 动画的层次感改由**内容元素自己的入场动画**承担（图标翻转、标语字距、格言逐字），背景不再参与淡入；
- 「减少动态效果」的降级分支同步去掉 `boot-in`。

## 验证

浏览器把动画冻结在第 0 帧后截图：页面主体（侧边栏、标题、卡片、按钮）**完全不可见**，只有遮罩背景。此前同一测试能看到完整主页。
